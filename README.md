# World Watch

日本語向けVRChatワールドの毎時ランキング。公式アクティブ一覧から最大500件の候補を取得し、総同接順・公開側人数順のTOP100を表示します。

公開URL：https://vrc-ranking-board.vrc-ranking-board.workers.dev/

## ローカル起動

```powershell
npm install
npm start
```

http://127.0.0.1:4173/ を開きます。`npm start` は実データ版をバックグラウンドで起動します。停止は `npm stop`。初回取得中は集計中と表示し、架空の人数は表示しません。

サンプルで画面だけを確認する場合は `npm run dev`。`.runtime/latest.json` があれば実データ、なければ明示された架空のサンプルデータを表示します。

実データの毎時更新を行いながら起動するには：

```powershell
npm run dev:live
```

このモードはVPSで自動集計された結果を5分ごとにSSH経由で取り込むだけです。人数収集はVPSのsystemd timerが毎時開始するため、PCやローカルサーバーを停止しても継続します。VRChatの秘密情報はPCにコピーしません。人数取得は候補数に応じて数分〜約40分かかり、完了すると最新の集計を置き換えます。

手動で既存の集計結果を取り込む場合は `npm run sync`、新しく収集して結果を取り込む場合は `npm run collect`。`.runtime/vps.json` に `host`、`user`、`port`、`key`、`knownHosts` を設定します。接続情報はGitHubに登録せず、秘密鍵そのものも保存しません。

## 画面

- VRChatのダークメニューを参考にした紺・シアンのテーマ。
- 総同接、パブリック人数、総同接の1時間前比によるランキング。
- ワールド名・作者検索、PC／Quest／iOSでの絞り込み。
- ワールド詳細、公開／非公開の内訳、48時間の観測推移。
- ブラウザー内だけに保存するお気に入り。
- `vrchat://launch?ref=vrchat.com&id=...&attach=1` によるPC版の直接起動と公式ページへのリンク。参考： https://planetvrchat.net/archives/18173
- 小さい画面でも人数比較と起動リンクが使えるレイアウト。

検索・フィルターは各ランキングのTOP100内を絞り込みます。急上昇は総同接の比較で、前の時間帯にも観測があるワールドだけを対象にします。公開側はAPIの集計であり、参加できる部屋の人数ではありません。

## 収集の分離

`collector/ranking_collector.py` はLinux用・Python標準ライブラリのみ。World CompassのSQLite、設定、認証Cookieを読み取り、専用ディレクトリの履歴DBに書き込みます。元の認証ファイルは保存・更新しません。元サービスの停止・変更も行いません。

日本語掲載判定は名前・説明・タグを中心にし、作者名だけを根拠にしません。`overrides.json` の `include`／`exclude` にワールドIDを追加して調整できます。両方にある場合は除外を優先します。この設定はアクティブ一覧外のワールドを順位対象に加えるものではありません。

通常のAPI取得間隔は4秒＋ランダムな余白。エラー時には追加待機。候補はIDで重複除去します。取得失敗や一覧からの脱落は0人として記録しません。履歴は30日保持し、公開用スナップショットには直近48時間の推移を含めます。24時間ピークは観測した値の最大で、時間内の真のピークではありません。

日本語向けではない新規候補の判定結果を専用DBに24時間キャッシュし、同じ候補の不要な詳細取得を抑えます。レート制限や通信エラーの再試行が尽きた場合は収集全体を中断し、最後のランキングを残します。

VPSの `vrc-ranking-board.timer` が自動収集を担当します。毎時07分から最大3分のランダムな余白を入れて開始します。VPS再起動後もtimerが起動し、停止中の取りこぼしは復帰時に1回実行します。実行中の同じサービスを二重起動しない仕組みと、収集コード内の排他ロックがあります。ローカル画面を起動するだけでは収集処理を開始しません。

## Cloudflareでの公開

Worker＋Static Assets＋D1で公開します。GitHubの変更はActionsでテストとdry-runビルドを確認します。

D1を作り、`wrangler.jsonc` の `account_id` と `database_id` を公開先の値に設定してマイグレーションを適用します。`INGEST_TOKEN` は32文字以上のランダムな値をWorkerのsecretとして設定し、VPSの専用tokenファイルと一致させます。VPS設定の `ingestUrl` が空の間はCloudflareへの送信を行いません。APIは認証済みスナップショットだけを受け付け、個人情報や余計なフィールドを保存しません。

他のアカウントへ公開する際は、設定のアカウントID・DB IDを自分のものに置き換えてください。秘密鍵・Cookie・送信用tokenはリポジトリへ登録しません。公開画面にはVRChat認証情報は不要です。

本サイトのVPSには送信先と専用tokenを設定済みです。毎時の集計完了時にCloudflareへ送信するため、PCを起動し続ける必要はありません。コード変更の自動公開は、CloudflareのWorker設定「Builds」でGitHubの `yuhi-neru/vrc-ranking-board` を連携すると有効になります。GitHub Actionsの検証だけでは本番公開されません。

## 検証

```powershell
npm test
npm run check
npx wrangler deploy --dry-run --outdir .runtime/worker-build
```

人数欠測、TOP100の切り替え、日本語判定、履歴の欠測区間、同じ時間帯の再取得、重複、アップロード認証、公開APIの未設定状態を検証します。

## 注意する範囲

取得候補内の順位であり、日本語ワールド全体の網羅性は保証しません。APIでGroup系が公開／非公開側にどう集計されるかは実測の検証を続ける必要があります。画像はAPIの公開URLを直接参照し、独自の画像配布はしません。VRChat非公式のサービスです。
